02
What is Claude Code?

Claude Code란 무엇인가

🤖
AI 코딩 에이전트
터미널 기반의 AI 코딩 어시스턴트. 코드 작성부터 디버깅까지 자동화
⚡
CLI 네이티브
VS Code, 터미널에서 바로 실행. npm으로 전역 설치 한 줄이면 끝
🧩
확장 가능
스킬, 플러그인, 마켓플레이스로 무한 확장. 팀 단위 공유 가능
03
Installation

설치 & 시작하기

# Claude Code 설치
npm install -g @anthropic-ai/claude-code

# 버전 확인
claude --version

# 실행
claude

Node.js 18+ 필요 | 전역 설치 한 줄이면 완료

04
Core Concepts

3가지 핵심 개념

📋
스킬 (Skill)
단일 업무 매뉴얼.
SKILL.md 파일 하나로 정의되는 재사용 가능한 작업 규칙
📦
플러그인 (Plugin)
배포용 패키지.
스킬 + 에이전트 + 훅 + MCP를 하나로 묶은 것
🏪
마켓플레이스
플러그인 스토어.
GitHub로 호스팅, 팀원이 설치해서 바로 사용
05
Skill Structure

스킬의 구조

# SKILL.md 파일 구조
---
name: ppt-maker
description: "웹 PPT를 자동 생성"
---

# 발동 조건
사용자가 "PPT 만들어줘" 요청 시 발동

# 생성 규칙
1. 단일 HTML 파일로 생성
2. 키보드 방향키 네비게이션
3. CSS 애니메이션 전환 효과
06
Sub-Agents Architecture

병렬 서브 에이전트

4개의 독립된 에이전트가 동시에 리서치를 수행하고,
메인 에이전트가 결과를 통합합니다.

Agent 1

Agent 2

Agent 3
키보드 네비게이션
📐
Agent 4

07
Plugin Packaging

플러그인 패키징

# 디렉토리 구조
ppt-maker-plugin/
├── .claude-plugin/
│ └── plugin.json # 필수!
├── skills/
│ └── ppt-maker/
│ └── SKILL.md
└── README.md

⚠️ 주의: skills/ 폴더는 루트에 위치! .claude-plugin/ 내부 아님!

08
Marketplace

마켓플레이스 구축

파일위치역할
marketplace.json.claude-plugin/마켓플레이스 카탈로그
plugin.json플러그인/.claude-plugin/플러그인 신분증
SKILL.mdskills/스킬명/실제 작업 규칙

GitHub 레포에 푸시하면 → 팀원이 바로 설치 가능

09
Team Installation

팀원 설치 방법

# 1. 마켓플레이스 추가
/plugin marketplace add username/coa-marketplace

# 2. 플러그인 설치
/plugin install ppt-maker-plugin@coa-marketplace

# 3. 사용
/ppt-maker-plugin:ppt-maker 발표 자료 만들어줘

자동 업데이트 ON → GitHub 푸시하면 팀원 자동 동기화 🔄
